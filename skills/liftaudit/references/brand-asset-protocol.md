# Brand Asset Protocol

## Asset Pack Rule

Build the asset pack before visual design. Do not create polished visuals from guessed identity elements.

## Look For

- Official logo files
- Alternate logo marks
- Favicon
- Hero, service, product, team, storefront, office, vehicle, uniform, equipment, and interior photography
- Social assets
- Existing icons and graphic elements
- Official press assets

## Required Files

- `02-assets/asset-manifest.csv`
- `02-assets/source-manifest.md`
- `02-assets/brand-snapshot.md`
- `02-assets/official/`
- `02-assets/references/`

## Asset Categories

- Official first-party assets
- Third-party reference material
- User-supplied assets
- Conceptual or generated assets

Never treat third-party customer photography as official brand material.

## Manifest Fields

Filename, asset type, source URL, official/reference status, file format, pixel dimensions, file size, intended use, rights or reuse caution, notes.

## Non-Negotiable Logo Rule

Keep the official logo unchanged unless Megan explicitly requests redesign. If refinement may help, mention it separately. Never silently substitute, redraw, approximate, recolor, invent, or image-generate the logo. Composite or place the real logo directly.
