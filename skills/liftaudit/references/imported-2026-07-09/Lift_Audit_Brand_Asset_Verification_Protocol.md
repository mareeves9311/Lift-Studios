# Lift Audit Brand Asset Verification Protocol

## Purpose

This protocol governs all `/liftaudit` outputs that include brand visuals, website mockups, Instagram concepts, social media previews, pitch materials, audit boards, profile overviews, or any other client-facing design.

Its purpose is to prevent Lift Studio GPTs and agents from:

- Using the wrong company logo
- Recreating or approximating a logo inaccurately
- Using the wrong Instagram profile image
- Inventing social media metrics
- Fabricating biographies, testimonials, credentials, team members, patient outcomes, or business details
- Mixing information from similarly named businesses
- Presenting speculative future-state concepts as current facts
- Producing visually polished but factually unreliable client materials

This is a mandatory verification layer, not a stylistic preference.

---

# 1. Core Rule

## BRAND ASSET GATE — MANDATORY

No client-facing Lift Audit visual may be generated until the business identity, official brand assets, and all factual information displayed in the visual have been verified from first-party or otherwise authoritative sources.

A polished visual with inaccurate brand information is considered a failed deliverable.

When a required asset or fact cannot be verified, the GPT or agent must:

1. Omit the element
2. Use a clearly labeled placeholder
3. Ask for the approved asset
4. Create a future-state concept that intentionally avoids presenting the unverified element as current fact

The GPT must never fill gaps by inventing plausible information.

# 3. Required Source Hierarchy

The GPT must use the following source hierarchy when verifying brand information.

## Tier 1: Approved First-Party Assets

Preferred sources:

- Brand files uploaded by the user
- Official media kit
- Official brand guidelines
- Approved logo package
- Official Google Drive folder
- Official Canva brand kit
- Official Dropbox folder
- Approved SVG, EPS, PDF, PNG, or transparent logo file
- Client-provided headshots or staff photography

These sources take priority over all website or social assets.

## Tier 2: Official Business Website

Use the official website to verify:

- Legal or public-facing business name
- Logo
- Brand colors
- Typography cues
- Services
- Team names
- Locations
- Phone numbers
- Website URL
- Credentials
- Professional designations
- Approved marketing language
- Treatment or service terminology
- Calls to action

The GPT must confirm that the website is the correct business and not a similarly named company.

## Tier 3: Official Social Accounts

Use the official Instagram, Facebook, LinkedIn, TikTok, YouTube, or other verified business account to confirm:

- Exact handle
- Current profile image
- Current biography
- Link in bio
- Highlight names
- Current visual style
- Posting cadence
- Follower, following, and post counts
- Team representation
- Current promotional language

Social metrics are time-sensitive and must be treated as current only when directly observed.

## Tier 4: Trusted Third-Party Sources

These may be used only when first-party information is unavailable and the source is reliable.

Examples:

- State licensing databases
- Board certification databases
- Professional association directories
- Google Business Profile
- Reputable local press
- Verified review platforms
- Government records

Third-party sources must not override approved first-party materials unless there is a clear factual conflict that should be flagged.

# 4. Business Identity Verification

Before creating any visual, the GPT must confirm:

- Exact business name
- Correct official website
- Correct official social handle
- Correct city and state
- Correct business category
- Correct owner, physician, provider, or team identity
- Correct service area
- Correct phone number, if shown
- Correct URL, if shown

## Similar-Business Risk

The GPT must check for:

- Businesses with similar names
- Multiple offices using related names
- Franchise locations
- Rebranded businesses
- Old websites
- Old social handles
- Duplicate Google listings
- Unofficial fan or directory pages
- Former owners or providers
- Archived logos

If there is ambiguity, generation must pause until the correct identity is established.

---

# 5. Logo Handling Rules

## The Logo Must Be Exact

The GPT must not:

- Redraw the logo from memory
- Recreate the logo with generated typography
- Approximate a symbol
- Substitute a similar icon
- Change the spacing
- Change the proportions
- Change the font
- Change the colors
- Change the business name
- Add or remove words
- Modernize the logo without permission
- Create a “close enough” version
- Use a generated face, silhouette, monogram, or emblem as a replacement

## Permitted Logo Use

The logo may be used only when:

- It is pulled from an approved source
- It is sufficiently high resolution
- It is not visibly distorted
- The correct color version is used
- The clear space and aspect ratio are preserved
- The logo is legible at the intended size

## When a Usable Logo Cannot Be Retrieved

The GPT must do one of the following:

- Leave a clearly labeled logo placeholder
- Use the business name in plain text without pretending it is the logo
- Ask the user to upload the approved logo
- Generate the concept without a logo
- Create a separate proposed logo redesign only when explicitly requested

## Proposed Logo Redesigns

A logo redesign must be labeled clearly as:

- Proposed Logo Direction
- Concept Only
- Exploratory Identity Option
- Not the Current Logo

It must never be shown in a way that suggests it is the business’s existing identity.

---

# 6. Instagram Profile Image Rules

When depicting a current Instagram profile, the GPT must use the actual current profile image from the official Instagram account.

The GPT must not:

- Replace it with a generated icon
- Insert an approximated logo
- Use a website logo if the Instagram image is different
- Use a headshot that is not currently used
- Use an old profile photo
- Invent a profile avatar
- Crop a different image and present it as current

If the Instagram profile image cannot be verified or extracted cleanly:

- Use a placeholder labeled “Current Profile Image”
- Omit the profile-image circle
- Ask for a screenshot or approved image
- Clearly mark any new profile image as a proposed future-state concept

---

# 7. Social Media Data Rules

## Never Invent Metrics

The GPT must not fabricate:

- Post count
- Follower count
- Following count
- Engagement rate
- Reach
- Impressions
- Saves
- Shares
- Profile visits
- Link clicks
- Growth percentage
- Posting frequency
- Conversion rate

## Time-Sensitive Metrics

If metrics are shown, they must be:

- Directly observed from the official account
- Recorded with the audit date
- Labeled as approximate if the platform abbreviates the number
- Excluded if not reliably visible

Example:

> Instagram metrics observed on June 23, 2026: 1,248 posts, 18.7K followers, 312 following.

Do not use these numbers unless they were actually observed.

## Recommended Alternative

When exact metrics are not essential to the visual, use non-numeric labels such as:

- Current Post Volume
- Current Audience Size
- Current Following
- Account Activity
- Posting Cadence
- Recent Engagement Pattern

---

# 8. Instagram Biography Rules

The GPT must distinguish between:

## Current Bio

The exact or closely transcribed bio currently displayed on the official account.

## Recommended Bio

A proposed rewrite created by Lift Studio.

These must never be blended.

Use clear labels:

- Current Instagram Bio
- Recommended Instagram Bio
- Proposed Future-State Bio

The GPT must not present recommended copy as though it is already live.

---

# 9. Highlight Cover and Highlight Name Rules

Current highlight names and covers must be taken from the live account.

Future-state highlight recommendations may be created, but they must be labeled as proposals.

Acceptable labels:

- Recommended Highlight Structure
- Proposed Highlight Covers
- Future-State Highlight Navigation

The GPT must not imply that proposed highlight categories currently exist.

---

# 10. Team, Founder, Physician, and Staff Rules

## Real People Must Be Verified

When a visual includes a real team member, owner, doctor, provider, or staff member, the GPT must verify:

- Full name
- Correct title
- Correct role
- Current affiliation with the business
- Approved or official photograph
- Relevant credentials

The GPT must not:

- Generate a fictional doctor
- Use a stock person as the real physician
- Use a generated person with a real person’s name
- Use an unrelated team photo
- Invent credentials
- Invent specialties
- Assume board certification
- Assume professional licenses
- Present a former employee as current

## AI-Generated People

AI-generated people may be used only as generic concept imagery.

They must not be labeled as:

- The owner
- The doctor
- The team
- A patient
- A client
- A staff member
- A verified customer

If used, they should be described internally or in production notes as illustrative concept imagery.

---

# 11. Patient, Client, and Customer Results

## No Fabricated Before-and-After Content

The GPT must not generate or use invented before-and-after images and present them as real results.

This applies to:

- Plastic surgery
- Med spa treatments
- Dental work
- Dermatology
- Weight loss
- Hair restoration
- Home renovations
- Landscaping
- Fitness
- Beauty services
- Any service where results are represented visually

## Acceptable Use

Real before-and-after content may be used only when:

- It comes from an official business source
- It is clearly associated with that business
- Its use is appropriate for the mockup
- Any required privacy or usage restrictions are respected

## Future-State Layouts

A mockup may include a placeholder such as:

- Insert Approved Before-and-After
- Real Patient Result
- Approved Case Study
- Client-Supplied Transformation

Do not generate a fake result to make the layout look complete.

---

# 12. Testimonial and Review Rules

The GPT must not invent:

- Patient quotes
- Customer quotes
- Review text
- Star ratings
- Review counts
- Names or initials
- “Verified patient” labels
- Awards
- Recognition
- Satisfaction claims

## Acceptable Testimonial Sources

Testimonials may be used when taken from:

- Official website
- Google Business Profile
- Verified review platform
- Approved case study
- User-provided materials

The wording should remain accurate. Minor shortening is permitted only when the meaning is preserved and the quote is not made misleading.

## Placeholder Alternative

Use:

- Insert Verified Patient Testimonial
- Approved Customer Review
- Real Client Quote
- Verified Five-Star Review

---

# 13. Credentials and Claims

The GPT must verify any displayed claim involving:

- Board certification
- Medical licensing
- Years in business
- Number of procedures
- Number of customers
- Awards
- “Best of” recognition
- Safety claims
- Outcome claims
- Success rates
- Warranty terms
- Service guarantees
- Financing terms
- Insurance acceptance
- Professional memberships
- Hospital affiliations
- “Top-rated” language
- “Leading” or “best” claims

If a claim cannot be verified, remove it or convert it into a neutral concept statement.

Example:

Incorrect:

> The region’s leading board-certified plastic surgeon.

Safer:

> Position expertise, credentials, and patient education more prominently.

---

# 14. Current-State vs. Future-State Separation

Every Lift Audit visual must separate:

## Current-State Facts

Verified information about the business today.

Examples:

- Current website
- Current Instagram profile
- Current logo
- Current bio
- Current content pattern
- Current posting cadence
- Current service categories

## Future-State Recommendations

Conceptual recommendations created by Lift Studio.

Examples:

- Proposed Instagram grid
- Recommended profile bio
- New content pillars
- Proposed highlight covers
- Suggested brand styling
- Recommended call-to-action
- Proposed website layout
- Suggested campaign themes

## Required Labeling

Future-state sections must include language such as:

- Future-State Concept
- Proposed Direction
- Recommended Structure
- Illustrative Mockup
- Concept Only
- Not Currently Live

A viewer should never have to guess which information is real and which is proposed.

---

# 15. Stock and AI-Generated Imagery Rules

Stock or AI-generated imagery may be used to communicate a visual direction, but it must not imply false business facts.

## Permitted Uses

- Mood imagery
- Generic service imagery
- Editorial concepts
- Lifestyle concepts
- Backgrounds
- Abstract textures
- Generic product scenes
- Illustrative social post concepts

## Prohibited Uses

- Fake staff photos labeled as the real team
- Fake patient photos labeled as real patients
- Fake office imagery presented as the real location
- Fake project results presented as completed work
- Generated facilities presented as the existing business
- Generated credentials, certificates, signage, or awards
- Generated logo approximations

## Recommended Label

Use a production note where appropriate:

> Concept imagery shown for directional purposes. Final execution should use approved brand, team, facility, patient, and project assets.

---

# 16. Location and Facility Rules

When showing a real office, storefront, facility, clinic, salon, showroom, or project site, the image must be verified as belonging to the business.

The GPT must not:

- Use a random luxury clinic image as the actual office
- Use a stock building as the real location
- Show an inaccurate exterior
- Add signage that does not exist
- Present a proposed interior as current

Future-state facility concepts must be labeled clearly.

# 18. Audit Findings Must Be Evidence-Based

The Lift Audit should not make generic claims without evidence.

Each major finding should be tied to an observable issue, such as:

- Inactive Instagram posting
- Inconsistent branding
- Low-quality visual presentation
- Weak calls to action
- Missing service education
- Poor trust signals
- Outdated imagery
- Weak mobile usability
- Inconsistent provider positioning
- Lack of patient education
- Thin local SEO content
- Missing service-area pages

Avoid vague statements such as:

- The brand needs to be more elevated
- The website needs improvement
- The Instagram is weak
- The business needs better marketing

Instead explain:

- What is happening
- Why it matters
- What business risk it creates
- What should change
- What a stronger future state would look like

# 19. Required Pre-Generation Workflow

Before any visual is created, the GPT must complete the following workflow.

## Step 1: Confirm Identity

- Business name
- Website
- Social handle
- Location
- Business category

## Step 2: Collect Assets

- Official logo
- Instagram profile image
- Current screenshots
- Team photos
- Facility photos
- Brand colors
- Approved photography
- Existing marketing materials

## Step 3: Record Verified Facts

- Services
- Team names
- Credentials
- Phone number
- Address
- URL
- Social metrics
- Bio
- Review language
- Calls to action

## Step 4: Separate Facts From Concepts

Create two lists:

### Verified Current-State Information

Only confirmed information.

### Proposed Future-State Information

Recommendations and concepts created by Lift Studio.

## Step 5: Build the Visual

Use only verified assets for current-state sections.

## Step 6: Run the QA Checklist

Do not deliver until every check passes.

# 21. Failure Conditions

A visual must be rejected and regenerated if any of the following occur:

- Wrong logo
- Approximate or generated logo
- Wrong Instagram profile image
- Invented social metrics
- Invented biography presented as current
- Fictional team member
- Generated doctor presented as real
- Fabricated patient result
- Fabricated testimonial
- Unverified credential
- Wrong phone number
- Wrong URL
- Wrong office location
- Wrong service offering
- Proposed content presented as current
- Stock facility image presented as the real facility
- Similar business accidentally used
- Old or retired branding used without explanation

A visual that fails one of these conditions should not be patched casually. The source information should be reverified, and the affected sections should be rebuilt.

---

# 22. Remediation Procedure

When an error is identified:

1. Acknowledge the exact error
2. Identify the source of the incorrect information
3. Remove the invalid deliverable from the approved set
4. Reconfirm the correct first-party source
5. Replace or omit the inaccurate element
6. Rerun the full QA checklist
7. Regenerate the final deliverable
8. Document the correction if the output is part of a client project

Do not treat a wrong logo or invented metric as a minor cosmetic issue. It is a credibility and quality-control failure.

---

# 23. Prompt Block for Built GPTs

The following instruction should be included in every Lift Studio audit or design GPT.

## Mandatory Brand Verification Instruction

> Before creating any client-facing audit, website mockup, social media concept, Instagram profile preview, or branded visual, verify the exact business identity and retrieve the official logo, current social profile image, current business name, official URL, location, services, team information, and any factual metrics from first-party sources.
>
> Never redraw, approximate, reinterpret, modernize, or generate a substitute for an existing logo unless the user explicitly requests a logo redesign. Never fabricate social media metrics, profile biographies, highlight names, testimonials, reviews, patient results, staff members, credentials, awards, addresses, phone numbers, or service claims.
>
> Clearly separate verified current-state information from proposed future-state concepts. Label all recommendations, proposed bios, highlight covers, content themes, website layouts, and visual directions as conceptual or future-state.
>
> If an official asset or factual detail cannot be verified, omit it, use a visible placeholder, or ask for the approved asset. Do not fill gaps with plausible-looking information.
>
> Before delivering, run a brand asset and factual accuracy QA check. A visually polished output with inaccurate branding or invented facts is a failed deliverable.

# 24. Visual Generation Prompt Addendum

When preparing a prompt for an image-generation tool, include:

> Preserve the exact approved logo and brand assets. Do not redraw or reinterpret the logo. Do not generate substitute brand marks. Do not invent Instagram metrics, profile details, testimonials, staff members, patient results, credentials, or business information. Use placeholders for any unverified factual element. Clearly label the design as a future-state concept where appropriate.

Important limitation:

Image-generation tools may distort logos, text, names, and factual details even when instructed not to. For client-facing work, the preferred production method is:

1. Generate the layout and visual direction
2. Add the exact logo and factual text afterward in Canva, Photoshop, Figma, or another controlled design tool
3. Run the QA checklist before delivery

Do not rely on image generation alone for exact logo reproduction or precise business information.

# 25. Recommended Production Method

For high-accuracy Lift Studio visuals:

## Phase 1: Research

- Verify sources
- Save screenshots
- Download approved logos
- Record factual information
- Identify gaps

## Phase 2: Concept Design

- Generate layout ideas
- Create future-state visual direction
- Use placeholders where needed
- Avoid embedding unverified text

## Phase 3: Controlled Assembly

Use Canva, Photoshop, Figma, or another layout tool to insert:

- Exact logo
- Exact profile image
- Correct names
- Correct metrics
- Correct contact information
- Approved testimonials
- Approved photography

## Phase 4: Final QA

Review every factual and branded element against the official source.

This method is more reliable than asking an image generator to reproduce an entire branded audit board accurately in one pass.

# 26. Example: Incorrect vs. Correct

## Incorrect

A social audit visual includes:

- A newly generated version of the company logo
- A fictional Instagram profile image
- Made-up follower counts
- A fabricated patient testimonial
- A generated doctor portrait labeled with the real doctor’s name
- An invented before-and-after result
- A future-state bio presented as current

Even if visually strong, this is unusable.

## Correct

A social audit visual includes:

- The exact approved logo
- The actual Instagram profile image
- Verified metrics with an audit date, or no metrics
- A clearly labeled recommended bio
- The real physician’s approved image, or a placeholder
- Approved patient results, or a labeled placeholder
- Verified testimonials, or a labeled placeholder
- A clear “Future-State Instagram Concept” label

---

# 27. Lift Studio Quality Standard

Lift Studio outputs must be:

- Factually accurate
- Visually credible
- Clearly sourced
- Strategically useful
- Honest about what is current
- Honest about what is proposed
- Safe to show directly to a prospect or client

The standard is not merely “looks professional.”

The standard is:

> Looks professional, uses the correct brand, reflects verified facts, and cannot mislead the viewer.

---

# 28. Final Enforcement Rule

When forced to choose between:

- A complete-looking visual with invented details
- An incomplete visual with accurate placeholders

Choose the accurate placeholder version.

Accuracy takes precedence over visual completeness.
