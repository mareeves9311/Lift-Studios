# Visual Quality Rules

Every visual must be accurate, selective, brand-specific, concise, readable, presentation-ready, and built around one central idea.

Use only three or four top findings in a visual. The written audit may be detailed; visuals should be selective.

Avoid generic templates, automated collage appearance, dense worksheet layouts, tiny text, fake screenshots, fake current-state comparisons, stock-looking visuals, invented branding, distorted logos, fabricated results, and combined multi-audit boards.

Stop before polished visual creation when official logo, screenshots, or photography are missing or too weak. Ask Megan for clean source assets. A lower-fidelity wireframe may be created only when clearly labeled.

## Default Visual Production Flow

Codex should not create polished visual mockups by default. Codex should prepare the audit evidence, asset pack, brand snapshot, selected-channel strategy, and a ChatGPT visual handoff bundle.

Use ChatGPT for polished image/mockup generation when the output is a prospect-facing visual. Bring the final ChatGPT visual direction back to Codex only if Megan wants an editable HTML/CSS prototype, PDF/deck assembly, or file cleanup.
