# Instagram Audit

## Inspect

- Exact username and display name
- Current bio and link
- Visible post/follower/following counts
- Profile image
- Highlights
- Grid and Reels
- Posting cadence
- Content categories
- Visual consistency
- Process and behind-the-scenes content
- Local discoverability
- Calls to action
- Conversion path

## Deliverables

- Instagram audit
- Recommended bio
- Link and CTA strategy
- Highlight structure
- Content pillars
- Posting cadence
- Reels and process-content recommendations
- Three-to-six-post feed concept
- Caption and CTA examples

Use actual profile details for the current state. Keep any proposed follower counts, engagement, or results out of mockups unless clearly hypothetical.
